# spacex-falcon9-analytics-ml
This repository contains an end-to-end data science project analyzing SpaceX Falcon 9 launches.
The project includes:

Data collection, wrangling, and preprocessing using Python and SQL

Exploratory Data Analysis (EDA) with interactive visualizations using Plotly and Folium

Machine Learning classification models to predict first-stage landing/reuse

A Plotly Dash dashboard for interactive analytics

Insights to estimate launch costs based on first-stage recovery

The project demonstrates the full data science pipeline, from data acquisition to predictive modeling, including visual storytelling and interactive dashboards.

Tools & Libraries: Python, Pandas, NumPy, Matplotlib, Seaborn, SQL, Plotly, Folium, Scikit-learn, Dash.
